# Centro Veterinario Guillena - Web Portal

Web platform developed for the Centro Veterinario Guillena clinic. This project features a fully functional public interface, conversion-oriented and adapted for mobile devices (Responsive Design).

## 🚀 Key Features

* **Responsive Design:** Full adaptation to mobile, tablet, and desktop viewports using the Bootstrap 5 grid system and utilities.
* **Django Architecture:** Clean, modular structure based on Django's MVT (Model-View-Template) pattern to ensure scalability for future phases.
* **Map Integration:** Interactive Google Maps iframe with precise business location, tailored for local usability.
* **Optimized UI/UX:** Interactive components including a floating button for direct WhatsApp contact, clear visual hierarchy, and corporate color palette integration.

## 🛠️ Technologies Used

* **Backend:** Python 3, Django
* **Frontend:** HTML5, CSS3, Bootstrap 5, Bootstrap Icons

## ⚙️ Local Installation & Setup

1. Clone the repository:
git clone https://github.com/MarcosGalG/web-centro-veterinario-guillena.git

2. Navigate to the project directory:
cd web-centro-veterinario-guillena

3. Start the local development server:
python manage.py runserver

4. Open your browser and visit: http://127.0.0.1:8000/
